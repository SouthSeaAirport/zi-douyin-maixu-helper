# 梓 · 捏捏麦序助手

适用于桌面 Chrome 和 Edge。在抖音直播间选好一款或几款商品，助手监听购物袋。第一款恢复可买时，助手点击其入口。**默认会在本次结算按钮可用时直接点击一次。支持免密的订单可能当场扣款。**

## 安装

1. 在仓库的 **Releases** 页面下载 `zi-maixu-helper.zip`。已经拿到 ZIP 的用户可以直接解压。
2. 在 Chrome 地址栏输入 `chrome://extensions/`。使用 Edge 时输入 `edge://extensions/`。
3. 开启「开发者模式」，点「加载已解压的扩展程序」，选择解压后的 **extension** 文件夹。文件夹里可以直接看到 `manifest.json`。安装后请保留该文件夹。
4. 打开要看的抖音直播间。已经打开的直播间刷新一次，左上角会出现「麦序助手」面板。

## 第一次使用前设置收货地址和付款方式

1. **登录同一个抖音账号。** 在准备用来抢购的电脑浏览器里打开直播间，点「全部商品」。如果提示登录，用手机上的抖音账号登录。换电脑或浏览器后，再确认一次。
2. **保存收货地址。** 在手机抖音点「我 → 右上角 ☰ → 我的订单 → 地址」。部分版本在「我的订单 → 更多 → 地址」。点「新增地址」，填好收货人、手机号、所在地区和详细地址，点「保存」。有多个地址时，可把常用地址设为默认。电脑结算页如果提示「新建收货地址」，也可以在那里填写并保存。[抖音收货地址说明](https://sf3-cdn-tos.douyinstatic.com/obj/ies-hotsoon-draft/douyin_agreement/privacy.html?hide_nav_bar=1)
3. **准备付款方式。** 确认手机能打开常用的支付 App，且所选银行卡或余额可用。想用抖音小额免密时，在手机抖音点「我 → 右上角 ☰ → 设置 → 支付设置 → 免密支付」。部分版本的入口在「我的钱包 → 设置 → 自动扣款/免密支付」。找到用于购物的「小额免密支付」或「抖音支付免密支付」，按页面提示开通，查看是否显示「已开通」及适用限额。免密是可选项，可以随时到同一入口关闭。支持免密的订单可能在助手点击结算按钮时立即扣款。[抖音支付免密服务说明](https://lf3-cdn-tos.draftstatic.com/obj/ies-hotsoon-draft/ulpay/106ef897-8ad1-4211-a21b-eb888a6268e8.html)
4. **提前看一眼电脑结算页。** 让助手保持停止状态，手动打开一件平时可买、带结算页的商品，查看是否带出了刚保存的地址，以及是否需要选规格、数量或支付运费。看到「提交订单」或「支付」就退出。只想看助手能否识别商品时，用「仅提醒」。「现货测速并提交」会实际下单。

## 选商品和开始守候

1. 打开目标直播间的「全部商品」。
2. 在助手中点 **「点选商品」**，然后点购物袋里目标商品的标题或图片。面板会显示选中的商品全名和标价。想同时守多个商品，点「再选一款」继续选择。
3. 点 **「开始守候并提交」**。让直播标签保持在前台，购物袋和目标商品行可见。默认会等售罄或待开商品恢复可买。几款同时开放时，一轮只进入一款、提交一次。等待期间可点「停止」。
4. 提交后，在抖音「我的订单」查看规格、数量、含运费金额和状态。电脑如果显示 **「订单已提交，待付款」** 并出现二维码，即使手机已开免密，也要用收银台列出的 App（如微信、支付宝或抖音）扫码，在手机上完成付款。回到订单页看到「已付款」或「待发货」，才算支付完成。若状态仍是「待付款」，先打开这一单查看，避免重复下单。

点 **「仅提醒」** 只观察商品何时可买。取消勾选「结算按钮出现就点一次」后开始守候，只自动打开商品入口。新上架商品的标价上限用于选货，结算按钮按页面当时的总额直接提交。

## 常用设置

| 想怎么用 | 操作 |
| --- | --- |
| 想看别人先抢完一轮 | 在「目标和守候方式」里勾选「先看到同款被抢光，再抢下一波」。选择多款后，可以等同场下一批候选商品。 |
| 等主播新挂链接 | 可输入已知商品的完整标题和价格，再勾选「允许目标首次进入可见商品列表时触发」。 |
| 测已在售的商品 | 只选一款，在「目标和守候方式」里点「现货测速并提交」。这会实际下单，面板显示从收到指令到入口点击、结算点击和订单回执的用时。 |
| 换电脑、窗口大小或显示缩放 | 在新浏览器重新安装并点选商品即可。桌面插件按网页元素定位。窗口变窄导致购物袋折叠时，重新展开「全部商品」。 |
| 手机或桌面购物袋无法读取 | 另附按设备校准的截图工具，只负责打开商品入口。[手机与截图工具说明](mobile/README.md) |

如果抖音改变页面结构，插件可能需要更新。如果商家要求先选规格、填地址或使用手机扫码，按抖音页面提示完成。库存分配和支付结果以平台订单为准。
